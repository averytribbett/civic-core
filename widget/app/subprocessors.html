Civic Core widget

Subprocessor List

Last updated August 16, 2026

Overview

Civic Core LLC uses the following subprocessors to host and operate the chat widget and related backend services. We require subprocessors to protect personal data under written agreements appropriate to their role.

We will update this list before engaging a new subprocessor that processes personal data, consistent with our client agreements.

Current subprocessors

Subprocessor Purpose Data processed Location
OpenAI, L.L.C. AI inference for chat responses and text embeddings Chat message content submitted for processing (ZDR configuration) United States
Google Cloud Platform (Google LLC) Application hosting (Cloud Run), operations logging API request metadata, application logs, chat payloads in transit United States (configurable region)
Firebase Hosting (Google LLC) Delivery of widget static assets IP address, browser metadata in hosting logs United States
Supabase, Inc. (PostgreSQL hosting) Database storage for chat logs and indexed public content Conversation messages, metadata, document embeddings United States (per project configuration)

What is not listed here

Subprocessors are third-party service providers that process personal data on our behalf in the cloud.

  • Open-source libraries (for example, Markdown rendering or HTML sanitization in your browser) run locally on your device. They do not receive your chat messages from Civic Core’s servers.
  • Internal software we run on our own infrastructure (application frameworks, database clients, and similar npm packages) is part of Civic Core’s service, not a separate subprocessor.

Changes

We will update this page when we add or replace a subprocessor that processes personal data. Questions: hello@civiccore.ai
